# IaaS：Azure Site RecoveryによるDRハンズオン

[リポジトリ TOP](../../../README.md) | [全体・進捗チェック](../01-IaaS-ASRによるDRハンズオン.md)

Ubuntu VM上にApacheと静的HTMLを構成し、Azure Site Recovery（ASR）で別リージョンへ複製します。テストフェールオーバーで復旧を確認した後、演習用の元VMを停止して実フェールオーバーし、復旧先で更新したHTMLを保持して元リージョンへ戻します。

実際のリージョン障害は起こしません。本番経路・DNSの切り替え、外部DBや認証基盤の復旧は対象外です。

## 参加者の開始手順

1. **開催前：** [参加者用の事前準備](./準備/00-参加者用の事前準備.md)の1・2章を実施し、Windows PCのツールとAzureへのログインを確認します。
2. **当日：** 同資料の3章に従って教材ZIPを取得・展開し、PowerShellでリポジトリルートを開きます。
3. [全体・進捗チェック](../01-IaaS-ASRによるDRハンズオン.md)で開始条件を確認し、[Bicepによる初期リソースの作成](./準備/00-Bicepによる初期リソースの作成.md)を実施します。
4. 展開とBastion接続を確認したら、[02：ApacheとHTMLの構成](./演習/02-ApacheとHTMLの構成.md)から順に進めます。

参加者向けの事前準備ではGit・Visual Studio Code・Azure PowerShell（Azモジュール）は不要です。教材はZIPで取得し、パラメータは導入済みのサクラエディタで編集します。

## 初期環境の作成

初期リソースは[00：Bicepによる初期リソースの作成](./準備/00-Bicepによる初期リソースの作成.md)で展開します。Portalで初期環境を手作業で作成する手順はありません。01はBicepの展開結果を確認し、Bastion接続するページです。

| 順序 | 手順 | 内容 |
|---|---|---|
| 00 | [Bicepによる初期リソースの作成](./準備/00-Bicepによる初期リソースの作成.md) | パラメータ設定、what-if、初期リソースのデプロイ |
| 01 | [Bicepデプロイ結果の確認](./演習/01-ネットワークとVMの作成.md) | リソース・ネットワーク確認、元VMへのBastion接続 |
| 02 | [ApacheとHTMLの構成](./演習/02-ApacheとHTMLの構成.md) | VM内でApacheと演習ページを設定 |

Bicepは両リージョンのネットワーク、元VM、Recovery Servicesコンテナー、キャッシュストレージなどを作成します。**Apache・HTMLの構成、ASRの複製有効化、必要なロール割り当ては行いません。** 「03」では既存のコンテナーを開き、コンテナー作成をスキップしてレプリケーション有効化から進めます。

テンプレートは[infra/main.bicep](./準備/infra/main.bicep)、設定は[infra/main.bicepparam](./準備/infra/main.bicepparam)、設定例は[infra/main-sample.bicepparam](./準備/infra/main-sample.bicepparam)を参照してください。ビルド・what-if・展開コマンドは初期リソース作成手順に掲載しています。

## 所要時間と完了条件

- 操作・確認の目安は**約210分**です。Bicep展開、初期複製、再保護、復旧ポイント生成の待ち時間は別途必要です。
- 各ジョブの待機上限は、確保時間に合わせて参加者が決めます。
- VMが起動しただけでなく、Apacheの応答とHTMLの内容を確認します。表示文字列だけで判断せず、PortalのVM・リージョン・IPアドレスとも照合します。
- 再保護が未完了の場合は先へ進まず、停止箇所と理由を記録します。未完了の操作を飛ばして「フェールバック完了」とは扱いません。

## 安全上の注意と後片付け

- 自分の演習IDと専用リソースグループを使用し、本番・共有リソースを操作しないでください。
- 元VMの停止、コミット、再保護、削除を行う前に、対象・影響・必要な組織承認を確認します。証拠はVM外へ保存します。
- VMへはBastion Developer経由で接続し、公開IPへSSH接続しません。演習用HTTPページには秘密情報や業務データを置かないでください。
- 演習用パスワードは他の環境に流用せず、リポジトリへ保存しません。Bicep展開後は手順に従ってパスワードの環境変数を削除します。
- **ASR演習開始後に、初期環境のBicepを再展開してリセットしないでください。**
- 最終削除は[08：クリーンアップ](./演習/08-クリーンアップ.md)の順序に従い、複製無効化・依存関係の解除を先に行います。VM停止だけで終了せず、ディスク・公開IP・キャッシュストレージなどの残存と費用を確認してください。
