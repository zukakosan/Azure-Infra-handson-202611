# BCDR ハンズオン：参加者用の事前準備

初期リソースは **Bicep** で作成します。当日使用するWindows PCで、**1章と2章を開催前に済ませてください。**

| 実施するタイミング | やること |
|---|---|
| **事前** | 1. ツールの準備 → 2. Azureへのログイン確認 |
| **当日** | 3. 教材ZIPの取得・ファイル確認 |

演習用サブスクリプションは参加者が選びます。この準備ではAzureリソースを作成しません。権限・クォータ・ポリシーの確認は[詳細資料](./00-事前準備と確認ポイント.md)を参照してください。

## 1. 必要なツールを用意する（事前に実施）

インストールは組織の端末管理ルールに従ってください。管理者権限が必要な場合や、ダウンロードが制限される場合は、事前に端末管理者へ相談します。

| ツール | 用途 | 導入方法 |
|---|---|---|
| ブラウザー（Microsoft Edgeなど） | 教材のダウンロード、Azure Portal、Bastionの利用 | Windows付属のEdgeなど、組織で利用可能なブラウザーを使用 |
| PowerShell | 手元のPCでAzure CLIを実行 | Windows付属のPowerShellをスタートメニューから起動 |
| Azure CLI | Azureへのログイン、Bicepのビルド・デプロイ | [公式のWindows向け手順](https://learn.microsoft.com/ja-jp/cli/azure/install-azure-cli-windows)から、PCの構成に合う最新版のMSIを取得してインストール。導入済みの場合も更新 |
| Bicep CLI | Bicepファイルとパラメータファイルの処理 | Azure CLI導入後、下記のコマンドでインストール |
| SAKURA（サクラエディタ） | Bicepのパラメータファイルを編集 | PCに導入済みのものを使用 |

**Git、Visual Studio Code、Azure PowerShell（Azモジュール）は不要です。**

### Azure CLIとBicep CLIの動作確認

インストール後、**PowerShellを開き直して**次のコマンドを1つずつ実行します。エラーがあれば原因を確認し、解決するまで先へ進みません。

```powershell
az version
az bicep install
az bicep version
```

**確認結果：** Azure CLIとBicep CLIのバージョンが表示されれば完了です。`.bicepparam`を使うため、どちらも最新版を使用します。Bicep CLIが導入済みの場合は、`az bicep upgrade`で更新してください。

| 困ったとき | 対応 |
|---|---|
| `az`が見つからない | PowerShellを開き直し、Azure CLIのインストール状況を確認 |
| Bicep CLIのダウンロードに失敗する | エラー内容を確認し、端末管理者へプロキシ・通信制限を相談 |

## 2. Azureへのログインを確認する（事前に実施）

**開催前に、一度ログインできることを確認します。** 教材のダウンロードは不要です。今回の演習に用いるアカウントとサブスクリプションIDを用意してください。

### ① コマンドを実行する

手元のPowerShellで次を実行します。

```powershell
az login --use-device-code
```

### ② リンクを開き、コードを入力する

1. PowerShellに表示された **リンク**をコピーし、ブラウザーのアドレスバーに貼り付けて開きます（通常は`https://microsoft.com/devicelogin`）。
2. 同じPowerShellに表示された **コード**をブラウザーに入力し、**次へ**を選択します。
3. **今回の演習に用いるアカウントでログインします。** 追加の本人確認が求められたら、画面の案内に従います。
4. サインインが完了したら、PowerShellに戻ります。サブスクリプションの選択が表示された場合は今回の演習に用いるものを選び、入力できる状態に戻るまで待ちます。

**PowerShellはログインが完了するまで閉じないでください。** コードは自分で実行したコマンドのものだけを使い、他人には共有しません。期限切れの場合は、①からやり直します。

### ③ 演習用サブスクリプションを確認する

`<演習用サブスクリプションID>`を、今回の演習に用いるサブスクリプションIDに置き換えて1行ずつ実行します。IDはAzure Portalの **サブスクリプション → 対象サブスクリプション → 概要** で確認できます。

```powershell
az account set --subscription '<演習用サブスクリプションID>'
az account show --query '{Name:name,SubscriptionId:id,TenantId:tenantId,State:state}' -o table
```

**自分が利用するサブスクリプション名・ID・テナントが表示され、状態が`Enabled`なら完了です。** 表示されない場合は、別のサブスクリプションを選ぶか、管理者へアクセス権を確認します。

### Azure Portalからのログイン

[Azure Portal](https://portal.azure.com/)を開き、同じアカウントでサインインします。**ディレクトリとサブスクリプション**で、演習用のテナント・サブスクリプションを選択します。権限確認や設定変更は不要です。

> 当日はBastionのブラウザー接続（HTTPS）と演習用Webページ（HTTP／TCP 80）を利用します。端末・接続ネットワークの利用制限がある場合は、事前に端末管理者へ相談してください。実際の接続はVM作成後に確認します。

### 事前準備の完了チェック

- [ ] Azure CLIとBicep CLIのバージョンが表示される
- [ ] `az login --use-device-code`でログインし、演習用サブスクリプションを選択できる
- [ ] Azure Portalに同じアカウントでログインできる

エラーが残る場合は、実行したコマンドとエラーを記録し、サブスクリプションまたは端末の管理者へ確認します。パスワードや認証コードは共有しません。

当日は`az account show`で対象を確認し、認証切れの場合は`az login --use-device-code`で再ログインします。

## 3. 教材をZIPで取得する（当日実施）

この章は当日実施します。教材ZIPの事前ダウンロードは不要です。

### ダウンロードと展開

1. ブラウザーで[教材リポジトリ](https://github.com/zukakosan/Azure-Infra-handson-202611)を開きます。
2. **Code → Download ZIP** を選択します。Gitは使用しません。
3. ダウンロードしたZIPを右クリックし、**すべて展開**します。
4. 展開先で、`BCDR`フォルダーが直下にあるフォルダーを開きます。ここが、以降のコマンドを実行する**リポジトリルート**です。

> ZIPの中から直接ファイルを開かず、必ず展開してから使用してください。展開先は、後から見つけやすいローカルフォルダーにします。

### PowerShellで教材の場所を確認

エクスプローラーでリポジトリルートのパスをコピーします。手元のPowerShellで、以下の`<展開先のリポジトリルート>`を実際のパスに置き換えて実行します。

```powershell
Set-Location '<展開先のリポジトリルート>' -ErrorAction Stop

Test-Path '.\BCDR\ハンズオン\IaaS\準備\infra\main.bicep'
Test-Path '.\BCDR\ハンズオン\IaaS\準備\infra\main.bicepparam'
```

**確認結果：** どちらも **`True`** になれば完了です。`False`の場合は、ZIPの展開先と現在のフォルダーを確認してください。展開先フォルダー名には、ブランチ名などの接尾辞が付く場合があります。

### SAKURAでパラメータファイルを開く

1. SAKURAを起動し、**ファイル → 開く**で、展開した教材の`BCDR\ハンズオン\IaaS\準備\infra\main.bicepparam`を選択します。
2. ファイルが見つからない場合は、ファイルの種類を **すべてのファイル** にします。
3. 日本語のコメントが文字化けせず読めることを確認します。文字化けする場合は、文字コードを **UTF-8** に指定して開き直します。

ここでは内容を変更せず、開けることだけを確認してください。以降の編集・保存でもUTF-8を使用し、拡張子を`.bicepparam`のまま保持します。`.txt`を追加しないでください。

### 当日の確認

- [ ] 教材ZIPを展開し、2つの`Test-Path`が`True`になる
- [ ] SAKURAで`main.bicepparam`を文字化けなく開ける

当日は演習ID・リージョン・VMサイズ・専用パスワードを決め、[Bicepによる初期リソースの作成](./00-Bicepによる初期リソースの作成.md)へ進みます。
